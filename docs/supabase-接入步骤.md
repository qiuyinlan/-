# 账号与云端同步（可选）

「回忆」的默认存储是**本机**：卡组保存在 `data/study-data.json`，
浏览器里还有一份备份。云端同步是可选的附加能力 —— 配好之后，
两台设备（比如电脑 + 手机）用同一个账号登录，卡组和复习进度就会对上。

| 事项 | 说明 |
| --- | --- |
| 是否需要 | 可选。不配置时应用完全照旧，数据只在本机 |
| 账号体系 | Supabase Auth（邮箱 + 密码），不用自己写后端 |
| 同步方式 | 一台设备一份「信封」推上云端，合并时**只做加法**，删除靠墓碑传播 |
| 冲突处理 | 乐观并发（rev），冲突时先合并再重试，不会静默覆盖 |

---

## 一、建 Supabase 项目

1. 打开 https://supabase.com/ ，注册/登录后 **New project**（免费档就够）。
2. 等项目初始化完成（约 1 分钟），进入 **Project Settings → API**，
   记下两个值：
   - **Project URL**（形如 `https://abcdefg.supabase.co`）
   - **anon public / Publishable key**（会打进前端 JS，是设计上公开的钥匙）

> ⚠️ 别拿成 **service_role / secret key**。那把能绕过访问规则，绝对不能进前端。
> 本项目在构建时会检查，拿错会直接拒绝并提示你换回来。

## 二、跑建表脚本

左侧 **SQL Editor → New query**，把 `supabase/schema.sql` 整段粘进去 → **Run**。

跑完在结果里确认：`rowsecurity = true`（脚本末尾的自检注释里有这条查询）。

## 三、打开邮箱登录

**Authentication → Providers → Email**，确认 **Enable Email provider** 是开的。

关于「确认邮箱」：
- 开着：注册后要先去邮箱点确认链接，才能登录（默认行为，推荐）。
- 关掉（`Confirm email` 关）：注册完直接就能登录，适合自己先用起来。

## 四、填环境变量并重新构建

项目根目录建 `.env`（参考 `.env.example`）：

```env
VITE_SUPABASE_URL=https://你的项目.supabase.co
VITE_SUPABASE_ANON_KEY=你的 anon / publishable key
```

> Vite 只在**构建时**读取这两个变量，所以改完要重新构建：
> `npm run build`，然后重启 `npm start`。

## 五、在应用里登录

打开应用 → 右上角云朵图标（或侧边栏底部状态条）→ 「账号与云端同步」：

1. 没有账号就切到「注册」，填邮箱 + 密码（Supabase 默认密码至少 6 位）。
2. 注册成功（并确认邮箱）后回来「登录」。
3. 登录成功会立刻同步一次。

### 首次同步的选择

如果**云端已经有卡片**、**这台设备也有卡片**，会弹出「用哪边」：

| 选项 | 结果 |
| --- | --- |
| 合并两边（推荐） | 两边新增的都保留；同一张卡片按较新的复习进度为准 |
| 用本机覆盖云端 | 云端那份被本机替换（云端独有的会丢） |
| 用云端覆盖本机 | 本机那份被云端替换（本机独有的会丢） |

之后两边自动合并，不再询问。

## 六、手机怎么用

`npm start` 启动的本地服务只监听 `127.0.0.1`，手机访问不到。
两种办法：

1. **静态部署**：把 `dist/` 传到任意静态托管（Vercel / Netlify / GitHub Pages 都行），
   手机上打开那个网址，登录同账号即可。没有本机文件服务时数据存在浏览器
   （localStorage）和云端，刷新不丢。
2. **局域网**：把 `server.mjs` 的监听地址改成 `0.0.0.0`（本机文件保存只在那台电脑上有效）。

## 常见问题

- **「云端还没有建表」**：`supabase/schema.sql` 没跑，或跑在了别的项目里。
- **「连不上云端的地址」**：先去浏览器直接打开项目 URL 试试；常见原因是网络、
  代理/安全软件拦截，或者 `.env` 里的 URL 写错了。
- **登录报「邮箱还没确认」**：去注册邮箱点确认链接；或者按第三节把「确认邮箱」关掉。
- **登录报「邮箱或密码不对」**：`Authentication → Users` 里能看到注册过的账号；
  也可能是密码小于 6 位被拒。
- **退出登录会删数据吗？不会。** 本机数据还在，云端数据也在，下次登录继续同步。
- **同一账号在换设备登录后数据「少了」？** 看一眼同步状态：同步失败/未同步时，
  本机显示的就是最近一次成功同步的副本。点「立即同步」再试。
